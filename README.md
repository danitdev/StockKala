# StockKala 📦

StockKala is an inventory management system built with **Node.js**, **Express.js**, **Sequelize ORM**, and **MySQL**.

The goal of StockKala is to provide a structured system for managing products, categories, and inventory operations while practicing real-world backend development concepts such as database design, relationships, authentication, and business logic.

The project is currently under active development.

---

# 🚀 Features

## Product Management

Manage inventory products with:

- Product name
- SKU (unique identifier)
- Price
- Stock quantity
- Description
- Product image
- Category assignment

---

## Category Management

Organize products using categories.

Features:

- Create categories
- Update categories
- Delete categories
- Assign products to categories

---

## Inventory Management

Track and manage stock levels.

Planned features:

- Stock quantity updates
- Stock movement history
- Inventory transactions
- Low-stock notifications

---

## Dashboard

Provide an overview of the inventory system:

- Total products
- Total categories
- Current stock levels
- Inventory statistics
